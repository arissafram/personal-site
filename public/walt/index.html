Walt

A little box that bounces across your web pages. Turn it on, off, or let it come out when you step away.

Download Walt for Chrome

Install (takes about a minute)

  1. Unzip walt.zip. Move the walt folder somewhere it can stay, like Documents. If you delete the folder, Walt stops working.
  2. In Chrome, go to chrome://extensions (copy and paste it into the address bar).
  3. Turn on Developer mode in the top right.
  4. Click Load unpacked and choose the walt folder.
  5. Click the puzzle-piece icon in the toolbar and pin Walt.

Chrome only lets you install extensions from the Chrome Web Store in one click, so this one is installed by hand.

Update to a new version

  1. Download the new walt.zip and unzip it.
  2. Replace your old walt folder with the new one, in the same place.
  3. In chrome://extensions, click the reload arrow on the Walt card.
  4. Refresh any tabs that were already open.
